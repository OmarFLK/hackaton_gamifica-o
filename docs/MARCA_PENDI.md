# Nome e identidade fornecidos pelo usuário

Em 06/11/2026 o usuário definiu **Pendi** como nome do sistema e forneceu quatro PNGs de marca. Os arquivos originais foram copiados sem alteração para `integration-kit/frontend/public/brand/`:

- `pendi-wordmark.png`: nome.
- `pendi-logo.png`: símbolo com nome.
- `pendi-symbol.png`: símbolo usado também como ícone do aplicativo.
- `pendi-variants.png`: prancha de referência.

Não foram geradas novas logos. O frontend, manifest, notificações e documentação de apresentação usam Pendi. Os documentos originais do briefing permanecem com o nome de trabalho SuperPed. `Pandi` permanece o nome do companheiro infantil, distinto da marca Pendi.

Compatibilidade: contas fictícias `@superped.demo`, campos/rotas do contrato, nome do arquivo SQLite e valor `source` da FAQ online permanecem os do briefing para facilitar integração com o outro desenvolvedor. Esses nomes internos não mudam a marca visual.
