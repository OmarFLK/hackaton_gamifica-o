# Componentes preparados antes da chegada da interface

O outro dev está construindo a interface geral e enviará a base pelo GitHub. Por isso os arquivos já preparados foram isolados aqui: **não constituem um aplicativo independente** e não devem substituir o frontend dele.

Disponíveis: componentes de medicamentos, cliente REST, tipos, fixtures de leitura, feedback e provider provisório de sessão. Build/TypeScript ainda não executados. Instalação npm foi interrompida após a decisão de aguardar a base visual.

Integração: [docs/INTEGRATION_NOTES.md](../docs/INTEGRATION_NOTES.md). Usar o provider, layout e cliente existentes no projeto final. O kit não contém CSS, entrada `main.tsx`, roteador ou páginas completas.
